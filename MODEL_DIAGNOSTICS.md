# Model Diagnostics & Q-Q Residual Plots

## 1. Residual Analysis Framework
Fitted statistical models provide:
- Residual vs fitted values plot coordinates.
- Residual distribution summary.
- Q-Q Plot sample vs theoretical normal quantiles.
- Heteroscedasticity detection (variance ratio check across lower vs upper fitted quantiles).
- Normality assessment warning (Shapiro-Wilk test).

## 2. Disclaimer
Residual diagnostics help researchers assess whether the chosen statistical model assumptions are appropriate.
