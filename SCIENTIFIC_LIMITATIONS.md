# Scientific Limitations & Scope Boundaries

## 1. Boundary Disclaimers
- **Correlation vs Causation**: Statistical association does NOT prove physical causation.
- **Sample Size Constraints**: Small sample sizes ($N < 10$) increase model variance and uncertainty.
- **Outlier Flagging**: Outliers are flagged for researcher review and are never automatically deleted.
- **No Synthetic Imputation**: Missing response values are stored as `missing` without zero-filling.
- **Phase Boundary**: STOP after completing Phase 15 — DO NOT implement Bayesian optimization, active learning, automatic laboratory control, or automatic model retraining.
