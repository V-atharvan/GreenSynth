# DOE Versioning & Immutability

## 1. Versioning Rules
- **Approved Version Locking**: Once a DOE Study version (e.g. `v1.0`) is approved, its configuration and design matrix runs are locked as immutable.
- **Regeneration (V2)**: Any modification to factors, ranges, or design methods creates a new study version (e.g. `v2.0`), preserving `v1.0` in historic records for scientific auditability.
