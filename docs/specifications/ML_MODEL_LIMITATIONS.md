# Machine Learning Scientific Limitations & Scope Boundaries

## 1. Scope Boundaries
- **No Physical Causation**: Feature importance scores represent empirical predictive associations, NOT physical or chemical causation.
- **Small Dataset Variance**: In materials science datasets ($N < 20$), prediction uncertainty and variance are higher.
- **Predictions Are Not Proof**: Predictions must be experimentally verified in the laboratory before drawing scientific conclusions.
- **No Automatic Control**: ML prediction output is strictly informational and does NOT directly actuate laboratory hardware.
- **Phase Boundary**: STOP after Phase 16 — DO NOT implement Bayesian optimization, active learning, or automatic recommendations until future phases.
