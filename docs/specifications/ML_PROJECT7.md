# Project 7 Machine Learning Demonstration

## 1. Demonstration Project Overview
- **Material**: Copper Oxide ($\text{CuO}$) Thin Films
- **Synthesis Method**: Phytochemical Spray Pyrolysis
- **Plant Extract**: Mulberry Leaf Extract in Ethanol

## 2. Features & Targets
- **Input Features**: Substrate Temperature (°C), Spray Rate (mL/min), Precursor Concentration (M), Extract Volume (mL).
- **Target Property**: Electrical Conductivity (S/cm), Optical Band Gap (eV), Crystallite Size (nm).

## 3. Demo / Synthetic Mode
If actual laboratory data is sparse, ML Demo Mode uses synthetic data explicitly marked `is_synthetic = true` and displays `"DEMONSTRATION DATA — NOT EXPERIMENTAL RESULTS."`
